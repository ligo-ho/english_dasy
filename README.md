# מאמן אוצר מילים באנגלית (Local-First)

אפליקציית Next.js ללימוד אוצר מילים באנגלית לדוברי עברית, עם ממשק RTL מלא ושמירה מקומית ב-SQLite.

## התקנה והרצה

1. התקנת תלויות:

```bash
npm install
```

2. הרצה מקומית:

```bash
npm run dev
```

3. פתיחה בדפדפן:

`http://localhost:3000`

## מסד נתונים

- הקובץ נשמר מקומית בנתיב:
  - `local_data/vocabulary.sqlite`
- אין תלות בשירותים חיצוניים בזמן שימוש רגיל באפליקציה.

## איפוס נתוני דמו

למחיקה ואיפוס מלא:

```bash
rm -f local_data/vocabulary.sqlite
npm run dev
```

בעלייה מחדש יווצר מסד נתונים חדש עם מאגר דמו.

## מבנה הטבלה להדבקה

בעת יצירת מאגר חדש יש להדביק טבלה מופרדת בטאבים (Tabs) ושורות חדשות (Newline), בדיוק 5 עמודות לכל שורה:

1. English
2. Correct Hebrew translation
3. Wrong Hebrew translation 1
4. Wrong Hebrew translation 2
5. Wrong Hebrew translation 3

דוגמה:

`Apple\tתפוח\tבננה\tענב\tאגס`

## מה האפליקציה כוללת

- דף בית עם מבחנים קיימים ומצבם
- יצירת מאגר מילים מטבלה מודבקת
- יצירת מבחן חדש לפי מאגר מילים
- רצף מלא:
  - מבחן → תוצאות → חזרה על טעויות אחרונות → מבחן חוזר
- שמירת מצב מבחן מקומית כדי שניתן יהיה להמשיך מאותה נקודה
- ללא אימות משתמשים וללא ניהול חשבונות
