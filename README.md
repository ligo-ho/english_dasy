# תרגול אוצר מילים באנגלית

אפליקציית ווב מקומית (local-first) לתרגול אוצר מילים באנגלית עבור דוברי עברית.
האפליקציה מאפשרת ליצור מאגרי מילים מטבלאות שמודבקות מ-Excel/Google Sheets, ולפתוח
מבחנים אינטראקטיביים שבהם המשתמש בוחר את התרגום הנכון מתוך 4 אפשרויות בעברית.

> כל הממשק בעברית, RTL, מותאם למחשב שולחני. אין משתמשים, אין הרשמה, אין צורך באינטרנט בזמן השימוש.

## דרישות מערכת

- Node.js 18+ (מומלץ Node 20 ומעלה)
- npm

## התקנה

```bash
npm install
```

החבילה `better-sqlite3` היא מודול native. אם ההתקנה נכשלת ייתכן שיהיה צורך בכלי build:

- Linux: `sudo apt-get install -y build-essential python3`
- macOS: `xcode-select --install`
- Windows: התקנת [Visual Studio Build Tools](https://visualstudio.microsoft.com/visual-cpp-build-tools/)

## הפעלה במצב פיתוח

```bash
npm run dev
```

האפליקציה תרוץ בכתובת [http://localhost:3000](http://localhost:3000).

## בנייה ל-production

```bash
npm run build
npm start
```

## איפה נשמר קובץ ה-SQLite?

הקובץ נוצר אוטומטית בנתיב:

```
./data/vocab.db
```

(התיקייה `data/` נוצרת בריצה הראשונה ואינה נכנסת ל-Git — ראו `.gitignore`.)

## איפוס נתוני הדגמה / מחיקת הכל

כדי למחוק את כל המאגרים והמבחנים ולחזור לנתוני הדגמה הראשוניים:

```bash
npm run reset-db
```

ההפעלה הבאה של האפליקציה תיצור את קובץ ה-DB מחדש ותטעין שני מאגרי הדגמה
("מאגר הדגמה - מילים בסיסיות" ו-"מאגר הדגמה - פעלים נפוצים").

## מבנה הטבלה להדבקה

בעת יצירת מאגר חדש, מדביקים טבלה ש**כל שורה בה בדיוק 5 עמודות** מופרדות בטאב:

| אנגלית | תרגום נכון | תרגום שגוי 1 | תרגום שגוי 2 | תרגום שגוי 3 |
| ------ | ----------- | ------------- | ------------- | ------------- |
| apple  | תפוח        | אגס           | בננה          | תפוז          |
| book   | ספר         | מחברת         | עיפרון        | עט            |

- שורות ריקות יידלגו בשקט.
- שורות שאינן כוללות בדיוק 5 עמודות יוצגו כשגיאה ולא יישמרו.
- ניתן להדביק ישירות מ-Excel או מ-Google Sheets — העתקה משם מפרידה תאים בטאבים.
- הטופס מציג תצוגה מקדימה של עד 20 השורות הראשונות לפני השמירה.

## זרימת השימוש

1. **דף הבית** — סקירה של כל המבחנים הפעילים, סטטוס נוכחי, אחוז הצלחה ומספר טעויות.
2. **יצירת מאגר חדש** — `/banks/new` — הדבקה של טבלת מילים ושמירה.
3. **יצירת מבחן חדש** — `/tests/new` — בחירת שם ומאגר. השאלות מעורבבות אקראית.
4. **מסך השאלה** — מוצגת המילה באנגלית ו-4 אפשרויות בעברית בסדר אקראי.
5. **מסך תוצאות** — תרשים, אחוז הצלחה, מספר תשובות נכונות וטעויות.
6. **חזרה על מילים שטעיתי בהן** — רשימה לימודית של המילים השגויות בסיבוב האחרון בלבד.
7. **מבחן חוזר** — שאלות חדשות רק על המילים השגויות מהסיבוב האחרון, ושוב מסך תוצאות.

הלולאה נמשכת עד שאין יותר טעויות בסיבוב, ואז המבחן מסומן כהושלם.

ניתן לחזור לדף הבית בכל שלב; המבחן ישמור את מצבו וניתן להמשיך אותו מאוחר יותר.

## ארכיטקטורה

- **Next.js 14 (App Router) + TypeScript**
- **better-sqlite3** — SQLite מקומי, חיבור יחיד באמצעות singleton.
- **Server Actions** — כל פעולות הכתיבה (יצירה, מענה על שאלה, מעבר בין שלבים) רצות בצד השרת.
- **טבלאות**:
  - `word_banks` — מאגרי המילים.
  - `word_items` — המילים במאגר (5 עמודות הטקסט).
  - `tests` — מבחנים, עם `state` ו-`current_round`.
  - `test_answers` — שורת שאלה בסיבוב מסוים, כולל `answered_correctly` ו-`position`.
- **ללא תלות חיצונית בזמן ריצה** — אין קריאות לאינטרנט, אין שירותי צד שלישי.

## הערות

- האפליקציה אינה כוללת אימות משתמשים. כל מי שניגש למחשב יראה את אותם המבחנים.
- מצב המבחן נשמר אחרי כל תשובה, כך שרענון או יציאה לא יפגעו בהתקדמות.
- הקוד עשוי להיות מאוחסן ב-GitHub, אך הריצה עצמה לא דורשת אינטרנט.
